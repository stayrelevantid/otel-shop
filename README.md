# OTel-Shop Lab

Laboratory project untuk mempelajari **OpenTelemetry distributed tracing** secara end-to-end:
3 microservices Golang (Order, Inventory, Payment) di-deploy ke **k3d Kubernetes**, dengan
OpenTelemetry Collector dan Jaeger sebagai telemetry backend.
